# \# 🚀 MediaFlow

# 

# Sistema de Digital Signage inteligente para gerenciamento remoto de campanhas multimídia em TVs, painéis digitais e dispositivos embarcados.

# 

# \## 🧠 Sobre o Projeto

# 

# O MediaFlow é uma plataforma desenvolvida para reprodução automatizada de vídeos, imagens e campanhas digitais em telas corporativas, TVs comerciais e painéis informativos.

# 

# A solução permite sincronização remota de conteúdo, gerenciamento centralizado de playlists, atualização automática de mídias e operação contínua 24/7 com alta estabilidade.

# 

# O sistema foi projetado para ambientes comerciais, publicidade digital, comunicação interna, painéis informativos e automação de mídia.

#

# 

# \## ✨ Principais Recursos

# 

# \- ▶️ Reprodução automática de vídeos e imagens

# \- Sincronização remota de playlists

# \- 🔄 Atualização automática de conteúdo

# \- Execução fullscreen automatizada

# \- ☁️ Gerenciamento centralizado

# \- Agendamento de campanhas por horário

# \- 📊 Monitoramento contínuo do player

# \- 🛠️ Recuperação automática em caso de falhas

# \- 🍓 Compatível com Raspberry Pi, Linux e Windows

# \## 🏗️ Arquitetura

# 

# O MediaFlow utiliza uma arquitetura centralizada onde os dispositivos conectam-se automaticamente ao servidor principal para:

# 

# \- baixar playlists

# \- sincronizar campanhas

# \- atualizar mídias

# \- receber comandos remotos

# \- monitorar status operacional

# 

# A reprodução ocorre localmente utilizando o MPV, garantindo:

# 

# \- alta performance

# \- estabilidade operacional

# \- baixo consumo de CPU e memória

# \- aceleração de hardware

# \- reprodução contínua em tela cheia

# 

# \---

# 

# \## ⚙️ Funcionalidades

# 

# \### Sincronização Inteligente

# 

# O player conecta-se automaticamente ao servidor para sincronizar campanhas e atualizar mídias em tempo real.

# 

# \### Agendamento de Conteúdo

# 

# Permite configurar playlists e propagandas específicas por horário e período.

# 

# \### Gerenciamento Remoto

# 

# Controle centralizado de:

# 

# \- dispositivos

# \- campanhas

# \- playlists

# \- volume

# \- atualizações

# \- conteúdo exibido

# 

# \### Recuperação Automática

# 

# O sistema monitora continuamente o player e reinicia automaticamente serviços em caso de falhas.

# 

# \### Atualização Automática

# 

# Elimina a necessidade de pendrives ou atualizações manuais.
